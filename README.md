# Antonio Galdes

Computer Engineer from Malta. I write software that runs close to the hardware: CUDA on GPUs, C on microcontrollers, and vectorised C++ on the CPU.

I graduated in Computer Engineering from the University of Malta with First Class Honours and a place on the Dean's List, and I have finished my MSc in Artificial Intelligence, with the viva still to come.

I am currently teaching myself robotics. I am still at the start of it, and most of what I build for that will appear here as I go.

## Projects

**[CUDA-3D-DWT](https://github.com/Expo39/CUDA-3D-DWT)**
A multi-level 3D discrete wavelet transform on the GPU, validated on the CHAOS medical imaging dataset.
`CUDA` `C++`

**[SIMD-Image-Processor](https://github.com/Expo39/SIMD-Image-Processor)**
Lanczos image resampling written with SIMD intrinsics.
`C++`

**[Threaded-Monte-Carlo](https://github.com/Expo39/Threaded-Monte-Carlo)**
Monte Carlo integration spread across threads, to see how far the speed-up goes.
`C++`

**[DTMF_Decoder](https://github.com/Expo39/DTMF_Decoder)**
A touch-tone decoder for a microcontroller, built on the Goertzel algorithm, with an LCD readout.
`C`

**[My_Cookbook](https://github.com/Expo39/My_Cookbook)** ([live site](https://expo39.github.io/My_Cookbook/))
A recipe site for family and friends, with serving scaling, unit conversion and a cook mode. A single Rust core runs both at build time and in the browser through WebAssembly, so the two always agree on an amount.

**[Code-Dojo](https://github.com/Expo39/Code-Dojo)**
A practice system for getting better at programming, using spaced repetition and timed drills, with Claude Code acting as a tutor that asks questions and reviews but never writes the answer.
`Python`
