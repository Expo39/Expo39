### Hi, I'm Antonio

I am a computer engineer from Malta, interested in GPU programming, embedded systems and robotics.

I graduated from the University of Malta with First Class Honours in Computer Engineering. I have also finished my MSc in Artificial Intelligence, and all that is left is the viva.

I am learning robotics at the moment, so expect that to show up here over time.

### Projects

- **[Uncertainty-Conditioned RL with Evidential Policy Networks](https://github.com/Expo39/Uncertainty-Conditioned-RL-with-Evidential-Policy-Networks-for-Autonomous-Systems)**: my MSc dissertation. An autonomous parking agent that takes its own localisation uncertainty into account, trained in CARLA with ROS 2.
- **[CUDA-3D-DWT](https://github.com/Expo39/CUDA-3D-DWT)**: a multi-level 3D wavelet transform on the GPU, tested on the CHAOS medical imaging dataset.
- **[SIMD-Image-Processor](https://github.com/Expo39/SIMD-Image-Processor)**: Lanczos image resampling using SIMD intrinsics.
- **[Threaded-Monte-Carlo](https://github.com/Expo39/Threaded-Monte-Carlo)**: multi-threaded Monte Carlo integration in C++.
- **[DTMF_Decoder](https://github.com/Expo39/DTMF_Decoder)**: a touch-tone decoder for a microcontroller, using the Goertzel algorithm.
- **[My_Cookbook](https://github.com/Expo39/My_Cookbook)** ([live site](https://expo39.github.io/My_Cookbook/)): a recipe site for family and friends, with serving scaling, unit conversion and a cook mode. One Rust core runs at build time and in the browser through WebAssembly.
- **[Code-Dojo](https://github.com/Expo39/Code-Dojo)**: a practice system for programming, with spaced repetition and timed drills. Claude Code acts as a tutor that asks questions and reviews, but never writes the answer.
